# Design
One task screen followed by a readable family note. The user requested this exact sequence.
Palette: blue #234b70, dark ink #1c3449, muted ink #526578, daylight background #edf3f8, white #ffffff.
Georgia headings give the family note a personal letter character; Segoe UI controls support familiar Windows reading.
Content width 880px; two-column form becomes one column below 600px. No images or decorative motion.
The form and note have distinct shapes. The family note has square corners and a blue top rule, so the detector's rounded-border warning does not apply to it.
Visible keyboard focus; labelled fields; live save and error messages. General guidance links to official insurance sources.
